***# HR Employee Analytics Dashboard***



***## Project Overview***



***This project analyzes employee data to identify attrition trends, salary patterns, workforce demographics, and employee performance insights.***



***The project combines SQL, Python, Pandas, and Power BI to perform data cleaning, analysis, and dashboard creation.***



***---***



***## Tools \& Technologies***



***- SQL***

***- MySQL***

***- Python***

***- Pandas***

***- Power BI***

***- GitHub***



***---***



***## Project Objectives***



***- Analyze employee attrition***

***- Identify high salary departments***

***- Evaluate overtime impact on attrition***

***- Analyze employee demographics***

***- Study workforce distribution across departments***

***- Build an interactive HR dashboard***
